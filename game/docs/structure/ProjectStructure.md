File Structure explanation:
- game/assets: all the external files for the game(png, mp3, ecc).It will be divided by in subdirectories based on the type or resource
- game/log: Will be used for all the logs obtained by compiling the code. To be divided in subdirectories later 
- game/docs: documentation of the project / TO-DO file in case it will be needed / Divided in subdirectories later
- game/resources: /https://docs.godotengine.org/en/stable/tutorials/scripting/resources.html, here there will be all .tres files that declare different declaration or variation of the same object(e.g if I have a weapon, I will declare here different type of weapon) divided in subdirectories later
- game/scenes: all the scene files
- game/script: all the scripts related to the scene and more
- addon: Contains third-party or custom Godot plugins that extend the engine's functionality. These plugins can provide additional tools, editor features or runtime functionalities, such as dialogue systems, camera management and terrain generation
